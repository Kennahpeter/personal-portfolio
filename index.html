02 — About Me

I'm a junior developer learning to build clean, functional interfaces with HTML, CSS and JavaScript. I like taking a problem apart, planning the solution properly, and only then writing the code — it's a habit I picked up building my first real project, a command-line calculator.

Right now I'm focused on front-end fundamentals: semantic markup, layout with CSS Grid and Flexbox, and writing JavaScript that handles edge cases instead of ignoring them. This site is itself part of that practice.
